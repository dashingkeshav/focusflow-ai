# FocusFlow AI — Chrome Extension Loading Guide

Follow these steps to load the FocusFlow AI Chrome Extension into Google Chrome or any Chromium browser (Brave, Edge, Opera):

1. Open Chrome and navigate to `chrome://extensions/`.
2. Toggle the **Developer mode** switch in the top right corner.
3. Click **Load unpacked** in the top left corner.
4. Select the `extension/` directory inside your `FOCUSFLOW-AI` project folder:
   `c:\Users\Maruti Jogdankar\OneDrive\Documents\major project\extension`
5. The extension icon will appear in your Chrome toolbar.
6. Click the FocusFlow AI icon to view your live Focus Score and quick controls.
